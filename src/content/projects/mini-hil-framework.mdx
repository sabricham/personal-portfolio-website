## Context

Professional HIL benches are expensive. This project shows the same ideas on hardware that
costs less than 100 €.

## Architecture

A Raspberry Pi acts as the test controller: it flashes the STM32, drives its inputs through
GPIO and reads its outputs over UART. Tests are plain pytest files.

```python
def test_led_blinks_after_boot(dut):
    dut.reset()
    assert dut.wait_for_uart("boot ok", timeout=2.0)
    assert dut.gpio("LED").toggles(within=1.0)
```

## Results

- Runs in GitHub Actions on a self-hosted runner.
- Documented so others can build the same bench.
