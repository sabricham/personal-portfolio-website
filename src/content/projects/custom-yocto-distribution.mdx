## Context

A product team needed a Linux distribution they could build, audit and update without
depending on a vendor SDK.

## My role

I set up the Yocto layers, the machine configuration and the image recipes, and documented
the build so the rest of the team could use it.

## Technical highlights

- Custom meta layer with machine, distro and image configuration.
- Read-only root filesystem with a separate data partition.
- A/B partition scheme for safe updates.

## Results

- Fully reproducible builds from a single command.
- Smaller image and faster boot than the vendor reference.
